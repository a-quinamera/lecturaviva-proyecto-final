# LecturaViva — aplicación Flutter

Cliente Android y web del catálogo de libros con reseñas, favoritos y asistente Gemini. La configuración, los comandos de ejecución, las direcciones de la API y las pruebas están en el [README principal](../README.md). La clave Gemini se configura exclusivamente en el backend; esta carpeta no contiene claves.

Capas: lib/ui → lib/controllers (GetX) → lib/data → HTTP, Hive y almacenamiento seguro.
